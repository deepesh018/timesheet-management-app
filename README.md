# 🕒 TIMESHEET MANAGEMENT APP

A simple and efficient **Timesheet Management Web Application** built using **Next.js 15**, **TypeScript**, and **TailwindCSS**.  
It allows users to log work hours, manage weekly entries, and track their progress through a clean and modular interface.

---

## 🚀 Features

- 🔐 **Authentication** with NextAuth (Credentials-based login)
- 📅 **Filter by Date Range** (This Week, This Month, This Year)
- ✅ **Filter by Status** (Completed, Incomplete, Missing)
- 📊 **Timesheet Table** with pagination
- ➕ **Add New Entry Modal** (Dynamic form for adding new tasks)
- 🧩 **Modular and Reusable Components**
- 📱 **Fully Responsive UI** with TailwindCSS
- ⚙️ **API Routes** for internal data fetching using Next.js API routes
